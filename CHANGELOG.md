# Changelog

Each release's section becomes its notes on GitHub and in the Mac app's update window. The first paragraph is the headline.

## 1.1.0

8-bit Voice is now its own open-source app, for Mac, Windows, Linux and phones.

- Apps for macOS (Apple silicon and Intel), Windows (x64 and Arm) and Linux (AppImage and .deb), and a website that works offline and installs to a phone's Home Screen.
- The Mac app updates itself, through Sparkle, the same way pitch.dog's other Mac apps do.
- Built for phones: a player that stays in reach while you scroll, iPhone audio that plays with the ring switch on silent, and saving clips through the share sheet.
- Open a `.txt` file of lines, or drop one on the window.
- The command-line tool makes exactly the same clips as the app.
