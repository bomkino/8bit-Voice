# Security

8-bit Voice runs entirely on your device. The web app and the desktop apps don't have accounts, don't send your lines or recordings anywhere, and don't load anything from other servers. The only network request the desktop app makes on a Mac is Sparkle checking this repository's releases for updates, and those updates are signed.

If you find a security problem, please don't open a public issue. Email [hello@pitch.dog](mailto:hello@pitch.dog) or use [GitHub's private vulnerability reporting](https://github.com/bomkino/8bit-Voice/security/advisories/new). Tell us what you found and how to reproduce it. We'll reply as soon as we can, fix it, and credit you in the release notes if you'd like.

Only the latest release is supported.
