# Fonts: CC0 1.0

`pd-body.woff2` (PD Body) and `pd-eyebrow.woff2` (PD Eyebrow) are pitch.dog's FontBlind v13 faces, which pitch.dog dedicates to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode). You can copy, change and use them for anything, commercially too, with no attribution needed.

The files here are cut down for the web: Latin characters only, and PD Eyebrow fixed at its narrow width. Both still come from the v3.0.0 release of the pitch.dog type system.

CC0 covers the font files only. The pitch.dog name and marks aren't covered.
